# GozarVpn Android

Kotlin + Jetpack Compose (Material 3), minSdk 26, VpnService with sing-box (libbox) and separate engine processes.

Build: `build-debug.cmd`, or `gradle :app:assembleDebug` with JDK 21 and the Android SDK.
Engine binaries are not in git; see [../BINARIES.md](../BINARIES.md) and the scripts in `tools/`.
