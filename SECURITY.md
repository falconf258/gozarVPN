# Security policy

Please **do not open a public issue** for security problems.

Report them privately through GitHub: **Security → Report a vulnerability** on this repository
(private vulnerability reporting). Include the app (Windows / Android), its version, what you found
and how to reproduce it. You will get an answer as soon as possible.

Problems in an engine itself (sing-box, Aether, Tor, Psiphon, mihomo, wireproxy-awg, OpenVPN)
should also be reported to that project; tell us too if GozarVpn ships an affected version.

لطفاً مشکلات امنیتی را به‌صورت عمومی (Issue) منتشر نکنید؛ از بخش
**Security → Report a vulnerability** همین مخزن، خصوصی گزارش دهید.
